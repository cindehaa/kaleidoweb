- **D016 (2026-08-17, user rule)** SOURCE TEXT IS THE VOICE. The reading layer of every experience is the source page's own text, verbatim, wherever the source's license permits reproduction (Wikipedia/arXiv: yes, with attribution + license notice; commercial editorial: no — use only uncopyrightable facts, or swap to an openly licensed source covering the same subject, as done for Manhattan → Wikipedia CC BY-SA). Generated connective prose shrinks to near-zero: structural headings, one-line interaction hints, and marked derivations only. This strengthens truth-preservation (the words ARE the source) and answers the user's dislike of AI-written prose. Existing builds already comply for their content layers; their glosses get trimmed in the next fix rounds.
- **D015 (2026-08-17, user rule)** Generated-to-fit imagery beats found-generic imagery, always: stock/found photography is banned from the vocabulary unless the photograph IS the subject's own artifact (a NASA frame, a print). Evidence: the only PD Manhattan photo available shows a shaker (the drink is stirred) and brand labels — found imagery routinely contradicts the derived world. Mechanisms: (a) dev-time, imagery is generated procedurally in the subject's palette (baked painterly canvas — bokeh/atmosphere/grain — plus drawn illustration, both marked "ours"); (b) runtime, an image-generation model joins the async enhancement stage (post-7s, cached), prompts derived from the material record; (c) truth rules unchanged — generated imagery is ambient or clearly illustrative, never evidence.
- **D014 (2026-08-17, user rule)** Paper-shaders (@paper-design/shaders) is the standing engine of the environment layer: every experience includes ≥1 shader-driven environment moment. Discipline unchanged: the shader is DERIVED from the subject's world (§5.8/§0.2 — dithering for woodblock, god-rays for launch light, grain for sumi night/liquid), never a generic backdrop; contrast floor, reduced-motion still, no-WebGL static fallback all stand. New requirement: ADAPTIVE animation — probe actual frame cost at runtime and freeze to a still only on slow devices; never hardcode speed 0 because the dev container is GPU-less (Apollo v4 baked that in — scheduled for fix).
- **D013 (2026-08-17, user directive)** Runtime generation target: **< 7 seconds** button-to-coherent-experience. Measured current dev pipeline: 1.5–3 h/experience (the offline factory). Runtime architecture: compose, don't write — instant typographic stage (~100 ms, built) → live extraction (deterministic, <500 ms) → ONE streaming fast-model call filling an Experience Spec (0.5–4 s) → interpreter hydrates scenes from the genre-kit/primitive library with client-side material derivation (3–7 s) → async bespoke enhancement + cache (7 s+; repeat visits <1 s). Prerequisite unlocked: 3 proven experiences exist, so the abstraction pass (Spec format + interpreter + kits distilled from them) is now the highest-leverage workstream. The Opus taste loop remains the offline factory growing kits/rules; it is never on the runtime path.
- **D012 (2026-08-16, user feedback + diagnosis)** "More visuals/motion/immersion — study Editions' source; three.js/shaders allowed; AI backgrounds allowed; balance plain vs styled." Diagnosis: we over-corrected into document-restraint (itself a model comfort zone); immersion comes from ATMOSPHERE — living environmental surfaces that render the subject's world — alternating with plain fast passages. Editions' measured technique profile (fetched source, Summer '25): 14 pre-rendered video loops + 131 images + Lenis smooth scroll + Motion-choreographed reveals + exactly ONE WebGL canvas — expensive-looking, cheap-running; atmosphere lives in assets, not in runtime. Program: (a) each experience gets an ENVIRONMENT LAYER budget — 2–4 atmospheric moments (canvas/shader/imagery) placed at ceremonial beats, everything else stays plain and fast; (b) vendored libs: three@0.185, @paper-design/shaders@0.0.80 (vanilla ShaderMount); (c) ambient motion is legal as environment when it renders the subject's world (§5 amendment) — the motion-means-something rule governs CONTENT motion, environment motion is governed by "does it place the reader in the subject's world"; (d) generative/AI imagery must remain non-representational or clearly marked (§7.4 unchanged) — atmosphere never fabricates evidence.
- **D011 (2026-08-16, user feedback + diagnosis)** "Less meta — present the content, not a summary of it." Diagnosis: our pages narrate their own design (openings explain the form; plates discuss 'this article'; apparatus explains apparatus). Form that needs a preamble is untrusted form. Rules: the surface voice speaks about the SUBJECT in the subject's world; self-reference (how to read this page, what this page does, what the encyclopedia failed to do) is demoted to end matter or deleted; instructions appear only at the point of interaction, in ≤1 line; the DESIGN_RATIONALE block is the sanctioned home for rationale. Show, don't tell about showing.
- **D010 (2026-08-16, user feedback + diagnosis)** Feedback: "improve via more whitespace." Diagnosis (the actual rule): emptiness is how a page declares amplitude — a figure is a figure because of the void around it. Our screens are cramped not from insufficient padding but from (a) surface over-budget (94.6% of source prose on the surface), (b) apparatus that never yields (header/minimap/nav/toggles present on every screen, so even "plates" are furnished), (c) equal-amplitude presentation (anchors and derivation notes at the same visual weight as content). Therefore: whitespace is EARNED BY OMISSION, never added as padding — uniform padding inflation is the metronome-pacing AI tell. Fixes flow upstream: editorial cut first, apparatus retreat second, then space appears as a consequence. Encoded causally in DESIGN_PRINCIPLES §4.13.
- **D009 (2026-08-16, meta-rule from user)** Treat user feedback as a SYMPTOM REPORT, not a prescription. Protocol: (1) reproduce the observation in the actual artifact, (2) diagnose the underlying cause, (3) fix the cause, (4) encode the causal principle — never the literal instruction — into the docs. Applying feedback verbatim without diagnosis is itself a failure mode (it patches one page and leaves the disease in the system).
- **D008 (2026-08-16, user directive)** (1) Less is more: omission is a design act — the surface carries only what earns its place; less-relevant information is hidden by default (but find-in-page reachable) or demoted by hierarchy; no pointless labels; the page must have an explicit information narrative (what matters most and why). Rubric #16. (2) Boldness is required: generic/no-impact design fails as hard as poor design. Rubric #17. (3) Operating norm: parallelize aggressively — research agents run continuously alongside builds; cheap semantic passes front-run future benchmarks.
- **D007 (2026-08-16, user directive)** Output must not "look like Claude generated." Two consequences: (1) an explicit anti-signature program — research and document the LLM-default design tells (docs/ANTI_SIGNATURE.md), audit every experience against them (rubric #14); (2) design-choice intentionality is now a scored dimension (rubric #15): every material choice needs stated provenance in the subject's own world (era, material culture, graphic history), enforced via a DESIGN_RATIONALE block in each experience. Evidence that triggered this: Apollo and Hokusai independently converged on near-identical bone-paper grounds + serif/mono pairings — individually defensible, collectively a system fingerprint.
